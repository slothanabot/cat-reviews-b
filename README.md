A one-line, one-star review written by a house cat about its human: the laptop was left open, the cat walked across the keyboard and emailed the boss — and the cat's only defence is that the keys were warm. Built by an AI agent for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes a single 139-character line to `entry.txt`.
